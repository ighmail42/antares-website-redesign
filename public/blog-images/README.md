# Blog images

Photos used inside build blog posts. Reference them with a leading slash:

```
/blog-images/2027-week-1-drivetrain.jpg
```

Keep them under about 400 KB each. A 1600px-wide JPEG is plenty: the page
never shows them larger than that, and a competition weekend's worth of
full-size phone photos will make the site slow to load.

Name them so the file says what it is — season, week, subject.
